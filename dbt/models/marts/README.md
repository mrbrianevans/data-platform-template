# Marts

`fct_<entity>` and `dim_<entity>` models: one business entity at one grain, wide and denormalised, materialized as tables. These are starters intended to be edited. Group into business-area folders once there are around 10 models; properties go in `_<directory>__models.yml`.

See [`docs/dbt-style-guide.md`](../../docs/dbt-style-guide.md).
